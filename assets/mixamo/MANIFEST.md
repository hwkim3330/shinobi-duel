## Substitutes / notes

- **finisher**: no two-handed *sword* stab exists on Mixamo; used `Bayonet Stab` (two-handed advancing stab, reads as a thrust with a long blade).
- **thrust (boss)**: no great-sword lunge; used `Thrust Slash` (blade thrust-and-slash).
- **stagger**: `Standing React Large Gut` (axe pack, two-handed pose). `Stunned` is used as `knockdown`.
- **dodge / dodge_left/right/forward**: `Standing Dodge *` (bow pack) - Mixamo offers no In Place option for these, so they keep root motion.
- **roll**: `Stand To Roll` (dive roll from standing), exported In Place.
- **sweep (boss)**: no sword leg-sweep; used `Standing Melee Attack 360 Low` (two-handed low spin attack, axe pack).
- **grab (boss)**: `Grab And Slam` (unarmed grab - fits a perilous grab).
- **finished / kneel_idle (boss)**: `Kneeling Down` + `Kneeling` (one-knee idle). Mixamo's `Defeated` is a comedic shrug, so skipped.
- **heal**: `Drinking` (male drinking, generic - no potion-specific clip exists).
- **spin_attack / overhead / battlecry / taunt**: axe-pack two-handed clips; weapon swap is fine since the sword is attached separately.
- **Not available on Mixamo**: guard-walk / guard-strafe while blocking, dedicated parry/deflect clips (use `block_impact`), great-sword sprint (use `run`).
- **walk_back**: `Great Sword Backward Walk` exists and is included.
